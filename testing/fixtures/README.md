# Pi evidence corpus

These are recordings of the real Pi TUI, not expected output generated by the
reader. `src/testing/fixtures.corpus.test.ts` validates the corpus and pins the
Stage 0 findings (`research/census-2026-09-22.md`); reader, projector and
sequencer tests replay these rows and events.

| Family | Capture and purpose | Redaction |
|---|---|---|
| `live/*.json` (18 scenarios) | Pi 0.87.1 TUI in a throwaway HOME / `PI_CODING_AGENT_DIR` / git project, scripted faux model, driven through a real PTY with `@xterm/headless` as the terminal. Each file holds every extension event the recorder saw (with the session file's size at that instant), the host-side file growth series, PTY/exit facts, the final screen, and every session file the scenario produced. | Synthetic prompts and a sandbox only. Paths are normalized (`/sandbox`, `sandbox` inside Pi's encoded session-dir names, `<scripts>`, `<pi-install>`). Pi's own system prompt text is replaced by `<text:length>` per section; `fileRowBytes` keeps each row's ORIGINAL byte length so doorbell offsets stay exact. |
| `durable/*.jsonl` | Hand-authored files for shapes no live recording produces. `v1-linear.jsonl`: the pre-tree format (no `id`/`parentId`, header without `version`, with `provider`/`modelId`/`thinkingLevel`), copied row-for-row in shape from Pi's own `packages/coding-agent/test/fixtures/large-session.jsonl` (MIT, earendil-works/pi@96724621) with its prose replaced. `v2-hook-message.jsonl`: the v2 tree with the `hookMessage` role that v3 renamed to `custom` (shape from `migrateV2ToV3` in `session-manager.ts`). | No user data; placeholders only. |

`meta.recordedWith` is the `pi --version` observed at capture and must equal
`support/upstream-versions.json` → `providers.pi.accepted` (the corpus test
enforces it). Bump both together after a compatibility pass.

## Regenerating

```bash
npm install --prefix /tmp/pi @earendil-works/pi-coding-agent@<version>   # never global
NODE_PTY_PATH=<a Node-ABI node-pty> npm run probe:live -- --binary /tmp/pi/node_modules/.bin/pi
npm test
```

`NODE_PTY_PATH` must point at a node-pty built for plain Node (Agent Code's own
copy is rebuilt for Electron's ABI). If node-pty's prebuilt `spawn-helper`
lost its execute bit (`posix_spawnp failed`), `chmod +x` it.

`@xterm/headless` is resolved from the parent `node_modules` (Agent Code's);
without it the probe answers DA1 by hand, records `meta.terminal: 'hand-answered
DA1'`, and the H8 corpus test fails on purpose.

Review every changed shape before committing: the recordings are the design's
ground truth, so a silent change here is a silent design change.
